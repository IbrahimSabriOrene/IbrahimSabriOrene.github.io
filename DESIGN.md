# Design direction

Audience: engineering teams and recruiters looking for agentic AI engineering. Purpose: show Ibrahim's personal work, engineering approach and contact details.

Palette: porcelain #f5f8fc, ink #182d45, cobalt #244ee8, pale blue #e5edff, slate #53647b, white #ffffff. Manrope carries a broad humanist headline; IBM Plex Sans carries readable project descriptions.

The memorable element is an interactive workflow canvas beside the introduction. Native buttons explain planning, tools, review and human approval. The remaining sections are quiet and left-aligned. Project rows vary by importance, rather than repeating a dashboard-card template.

```
Name                         Work / Approach / Contact / EN TR
Introduction                 Interactive agent workflow
Featured multi-agent work    Supporting personal prototypes
MCP tools                    Four compact tool entries
Engineering approach         Continuous employer timeline
Contact                      GitHub / LinkedIn
```

Critique: fake live terminals, generic counters and network particles would add decoration without explaining the work. Use a labeled illustrative workflow and honest prototype descriptions instead. Static HTML, CSS and a small script are sufficient. No private company project names or private source files are published.
